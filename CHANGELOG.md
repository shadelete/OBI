# Зміни (Changelog)

Усі зміни до застосунку OBI. Формат засновано на [Keep a Changelog](https://keepachangelog.com/uk-UK/1.1.0/).

## [0.1.3] — 2026-09-02 (стабільна)

### Додано
- Обробка об'єктів типу **TFurnAsm** у скрипті OBI.js — тепер вони вивантажуються в базу даних як фурнітура (найменування, артикул, кількість).
- **Вікно налаштувань** (кнопка-шестерінка у шапці):
  - Перемикання **теми**: світла / темна (через CSS-змінні в `styles.css`).
  - Перемикання **мови інтерфейсу**: українська / російська (словар `I18N` у `renderer.js`, функція `t(key)` + атрибути `data-i18n`/`data-i18n-ph`).
  - Блок «Про застосунок»: **версія**, **автор** (Alexander Bondarenko), **посилання на GitHub**.
- **Файл налаштувань користувача** `config/config.json` (тема, мова), створюється/читається поряд із exe; `config/` додано до `.gitignore`.
- IPC-методи `get-config`, `save-config`, `get-app-info` (у `main.js`/`preload.js`).
- Документацію структури UI/рендера, стилів, налаштувань та i18n в `AGENTS.md`.

### Виправлено / змінено
- Перекладено динамічні рядки інтерфейсу (списки, статистика, діалоги) на українську/російську.

### Не змінено
- Версію не піднімали (0.1.3) — це проміжне доопрацювання стабільної версії; налаштування входять у наступний мажорний реліз.

### Додано
- **Правила фурнітури** (`data/fit_rules.json`): програма запам'ятовує обраний тег фурнітури і при завантаженні нових проектів **автоматично розкидає** позиції по тих самих тегах, а також вимикає в експорті фурнітуру з накопиченого **блеклісту**.
  - Запам'ятовування **по артикулу** (`f.code`) і, якщо артикула немає, **по імені** (`f.name`): словники `tags`/`tagsByName` та `blacklist`/`blacklistByName`.
  - Файл правил зберігається разом із `db.json` (через `save-db`) і є **переносним** (можна передати іншому користувачу).
  - **Окреме вікно «Правила фурнітури»** (`src/fit_rules.html`+`src/fit_rules.js`), відкривається з налаштувань: дві вкладки — список відомої фурнітури **по тегах** та **чорний список** (з можливістю видалити позицію зі списку).
  - У `AGENTS.md` додано розділ про правила фурнітури та фіксування у `CHANGELOG.md`.
- **Назва проекту в шапці вікна** (між логотипом OBI та кнопкою «Відкрити замовлення») — показує найменування виробу з Базиса.
  - Скрипт `OBI.js` витягує **найменування виробу** з глобальної змінної `Article.Name` (з fallback на `currentFileData.article.Name`).
  - **JSON називається іменем виробу** і зберігається в окремій папці `data/projects/<Найменування>.json` (у двох місцях: поряд зі скриптом та поряд з exe).
  - Шлях активного проекту записується в `data/current_project.txt`; `main.js` читає його через `dbPath()` (fallback на `db.json`, якщо імені нема).
  - Новий IPC `get-project-name` → `window.api.getProjectName()`, показ у `renderer.js` через `renderProjectName()`.
  - `main.js` `dbPath()` визначає активний проект як найсвіжіший `.json` у `data/projects/` (fallback на `db.json`); діалог «Зберегти замовлення» за замовчуванням пропонує ім'я активного проекту (замість `order.json`).
- **Керування проектами** (збереження / відкриття / перейменування):
  - Кнопка «Зберегти замовлення» більше **не питає куди зберегти**: просто перезаписує поточний файл проекту в `data/projects/`.
  - Кнопка «Відкрити замовлення» відкриває **модальне вікно зі списком збережених проектів** (з `data/projects/`), клік відкриває вибраний.
  - Назва проекту в шапці — **клікабельна**: клік перетворює її на поле введення; Enter/втрата фокуса перейменовує й **файл json** (через IPC `rename-project`).
  - Нові IPC у `main.js`/`preload.js`: `get-projects` (список `{name,path,mtime}`), `rename-project` (перейменування файлу), `load-project(path)` (завантаження по шляху); активний проект відстежується модульною змінною `activeProjectPath`.
  - Додано модальне вікно `#project-picker-modal` у `src/index.html` + стилі `.project-list/.project-item` у `src/styles.css`.

### Виправлено
- Центрування колонки «Різ/паз» у листі «Матеріали» Excel-експорту (раніше вирівнювалася вліво).
- Кількість деталей матеріалу тепер **завжди** відображається в інтерфейсі (навіть якщо 1); для кількох позицій показується просто число (наприклад «2»), без значка «×».
- **Сортування фурнітури всередині тега** drag&drop: тепер позиції можна переставляти місцями в межах одного тега (раніше рядок повертався на своє місце після перенесення).
- **Видалення фурнітури за клавішею Delete/Backspace** для вибраних позицій (у т.ч. після перенесення) — крім кнопки «✕» у самому рядку.
- **Артикул профілю**: тепер витягується з назви профілю (формат «(артикул NNN)») і відображається в інтерфейсі (скрипт OBI.js).

### Змінено
- Логіку перенесення фурнітури між/всередині тегів (функції `applyFitMove`, `findBeforeRowId` у `src/renderer.js`); збережено багатовибіркове перетягування.

### Додано (масштабне оновлення інтерфейсу)
- Нова структура інтерфейсу: замість вкладок — бічна панель (sidebar) + панель списку + панель деталей (детальний вигляд матеріалів/профілів).
- Верхня панель (TopBar) з кнопками мінімізації/максимізації/закриття, що працюють через IPC.
- Пошук по базі (search-input) з підсвіткою результатів.
- Список картками: матеріали та профілі як клікабельні картки з коротким зведенням (назва, артикул, кількість, товщина тощо).
- Панель деталей: вкладки Кромка / Деталі / Додаткова інформація для кожного матеріалу; профілі — вкладки Розміри / Додаткова інформація.
- Групування: клік по картці відкриває деталі з групуванням за позицією та кількістю.
- Виділення: підтримка маркіза (marquee + Ctrl/Shift) для масового вибору, виділення/зняття виділення, видалення, копіювання/вставка.
- Статистика: зведений блок у бічній панелі з загальною кількістю позицій за категоріями.
- Кольорова схема (темна/світла), шрифти, стилі елементів керування; зміна API для масимізації вікна.
