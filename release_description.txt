ОБІ 0.2.0-beta — найбільше оновлення за весь час!

Це бета-випуск, тож чекаємо на ваш фідбек: знайшли баг — пишіть у issues.
Апдейт встановлюється в один клік прямо з застосунку (кнопка «Оновити» в налаштуваннях), без ручного скачування.

────────────────────────────
🔥 Найжирніші зміни
────────────────────────────

1) ПОВНІСТЮ новий інтерфейс
   • Замість вкладок — бічна панель + список карток + детальний вигляд.
   • Живий пошук по базі з підсвіткою результатів.
   • Кожен матеріал/профіль — клікабельна картка зі зведенням (назва, артикул, кількість, товщина).
   • Деталі матеріалу: вкладки «Кромка» / «Деталі» / «Інфо»; профілі: «Розміри» / «Інфо».
   • Групування деталей за позицією та кількістю.
   • Виділення маркізом (marquee) + масові дії: видалення, копіювання/вставка.
   • Перетягування фурнітури між тегами та всередині тега.

2) Правила фурнітури, які запам'ятовують вашу роботу
   • Застосунок запам'ятовує, у який тег ви закинули фурнітуру, і при наступних замовленнях розкладає її автоматично.
   • Чорний список: позиції, які ви вимкнули з експорту, більше не з'являються.
   • Окреме вікно «Правила фурнітури» зі списком по тегах і чорним списком.
   • Правила переносні — можна передати іншому користувачу.

3) Зручна робота з проєктами
   • JSON автоматично називається найменуванням виробу (Article.Name) і складається в окрему папку data/projects/.
   • Назва проєкту видно в шапці вікна.
   • «Зберегти» — в один клік, без діалогу (тихо оновлює поточний проєкт).
   • «Відкрити» — список збережених проєктів, клік відкриває.
   • Клік по назві проєкту в шапці = швидке перейменування (разом із файлом).

4) Автооновлення (headliner)
   • Застосунок сам знаходить нові версії на GitHub.
   • Кнопка «Перевірити оновлення» + «Оновити» — скачування, заміна exe і перезапуск у один клік.
   • Можна ввімкнути автоперевірку при запуску.
   • Розумна семантика: beta оновлюється на новіші бети і на фінальну версію, стабільна ніколи не відкочується назад.

────────────────────────────
🛠 Виправлення та дрібні покращення
────────────────────────────
   • Кількість деталей матеріалу завжди показана (навіть якщо 1).
   • Артикул профілю витягується з назви «(артикул NNN)».
   • Фурнітуру можна видаляти клавішею Delete/Backspace.
   • Центрування колонки «Різ/паз» в Excel-експорті.

────────────────────────────
📁 Що в архіві
────────────────────────────
   • OBI.exe — портабельний застосунок (без установки).
   • OBI.js — скрипт для САПР «Базис» (згенерувати дані проєкту).
   • icon.bmp — іконка.

📋 Як запустити
  1. Розпакуйте OBI-0.2.0-beta.zip у будь-яку теку.
  2. У «Базисі» запустіть OBI.js — він випише json проєкту та запустить застосунок.
   (або відкрийте OBI.exe напряму — прочитає наявні дані).
